# 提取 Sim-Fusion 为独立模块

## 问题概述

当前的 sim-fusion 优化功能嵌入在 `src/sim_fusion_optimizer.py` 文件中，该文件依赖于其他模块如 `hybrid_optimizer` 和 `optimization_engine`。这种耦合导致以下问题：

1. **依赖复杂**：需要导入多个模块才能使用 sim-fusion 功能
2. **重用困难**：难以在其他项目中独立使用 sim-fusion 优化
3. **测试复杂**：测试时需要模拟多个依赖模块
4. **代码分散**：sim-fusion 的核心逻辑分散在多个文件中

## 建议解决方案

将 sim-fusion 优化方法提取为一个独立的、自包含的 Python 文件：

1. **独立模块**：创建 `sim_fusion.py` 文件，包含所有必要的功能
2. **最小依赖**：仅依赖必要的第三方库（qibo, pytket）
3. **清晰接口**：定义简洁的 `sim_fusion()` 函数作为主要入口
4. **完整注释**：提供详细的中文注释说明算法流程
5. **统计信息**：包含优化结果的详细统计类

## 实现范围

提取的核心功能包括：

1. **主优化函数**：`sim_fusion(circuit, **kwargs)`
2. **统计信息类**：`SimFusionStats` 用于记录优化效果
3. **便捷函数**：`quick_sim_fusion()` 等简化接口
4. **错误处理**：优雅的错误处理和回退机制
5. **完整文档**：函数和类的详细文档字符串

## 预期收益

1. **提高可维护性**：集中管理 sim-fusion 相关代码
2. **增强重用性**：可作为独立模块在其他项目中使用
3. **简化测试**：减少依赖，使单元测试更简单
4. **改善用户体验**：提供简洁明了的接口
5. **便于扩展**：独立模块更容易添加新功能

## 兼容性考虑

1. **向后兼容**：保持现有 `sim_fusion_optimizer.py` 的接口不变
2. **渐进迁移**：用户可以逐步迁移到新的独立模块
3. **功能对等**：确保新模块提供相同的优化效果
